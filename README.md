# Spend Tracker V20.2

Local-first Android-friendly PWA.

## Files
- index.html: runnable app
- source/index.html: source copy
- manifest.webmanifest: PWA manifest
- sw.js: service worker
- icons/: PWA icons

## Data
Financial data remains in browser local storage. The ZIP contains no user financial data.

## V20.2 focus
On-device personalization engine with a large local message/visual library, context-aware selection, anti-repeat history, Money/Wealth personalities, adaptive headers, and Brain Food integration.
